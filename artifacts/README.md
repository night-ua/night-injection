# Night Injection downloads

Two x64 distributions are generated by the root `build.ps1` script:

- `NightInjection-Portable.zip`: extract the complete archive, then run `NightInjection.exe`. Keep the extracted files together.
- `NightInjection-Setup.exe`: installs for the current Windows user, creates a Start menu shortcut, optionally creates a Desktop shortcut, and registers Night Injection in Windows Installed apps.

The Setup destination is `%LOCALAPPDATA%\Programs\NightInjection`; administrator access is not required. Uninstalling keeps settings, history, logs, and cache under `%LOCALAPPDATA%\night-injection`.

Both files are self-contained x64 builds. They are unsigned development artifacts, so Windows may display a publisher warning. Verify their values against `SHA256.txt` before distribution.
